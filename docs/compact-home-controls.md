# 主畫面圓形入口與資料說明彈窗

更新：2026-11-08。依使用者確認的操作方式實作。

## 主畫面入口

番茄鐘與相機預設收合，呈現淡藍色半透明圓形按鈕，大小 48 × 48，分別顯示時鐘與相機圖示。第一次點擊只展開，不啟動計時、重試相機或重新校正；展開後可用右側關閉圖示收合。閒置 3 秒會自動收合；互動後重新計時，按住期間不自動收合。收合不會停止或暫停番茄鐘，倒數本身的每秒更新也不會重設收合計時。

### 角色位置

主畫面角色保留原本大小，向下平移可用畫面高度的 12%（限制為 64–120 邏輯像素），減少上方對話框遮住臉部的情形。背景維持填滿畫面；超出畫面下緣的角色部分由視窗裁切。這是畫面位置調整，不更動表情、動作或偵測流程。角色與對話框的實際距離仍待手機畫面確認。

### 番茄鐘

- 沒有進行中的場次：展開顯示「1 分鐘快速體驗」，再點圖示或文字啟動既有體驗流程。
- 已有進行中或暫停的場次：展開顯示「專注場次進行中」，再點圖示或文字進入任務頁管理番茄鐘，不另開或重設場次。
- 相機啟動中、沒有即時相機、仍在校正時，沿用原本的一分鐘體驗限制與提示。
- 主畫面底部原有倒數及暫停／繼續操作繼續可用。

### 相機

- 第一次點擊相機圖示，展開目前來源：正在啟動、即時相機、即時相機・校正中、測試影片或未就緒。
- 即時相機且校正已完成時，展開區顯示「重新校正」。
- 測試影片或未就緒時，展開區顯示「重試相機」。
- 校正中不提供重複校正按鈕；啟動中不提供重複重試。
- 收合時透過圖示顏色與長按提示保留來源狀態資訊；展開後顯示文字來源。

## 資料與隱私

設定頁入口改為置中彈出視窗，四周保留原設定頁背景。標題、右上關閉與底部關閉按鈕固定，中央六段說明可以捲動；關閉後回到同一個設定頁。

文字已依審閱草稿套用，見 [資料與隱私文案](data-privacy-copy-draft.md)。疲勞氣泡亦已改為「眼睛可能有些疲勞，先休息一下再繼續吧。」

## 對話框出現時的上方深色分界

使用者提供截圖，顯示對話框出現時，上方有橫向深色分界。程式中角色下移使用原生 Live2D 視窗平移，而對話框 BackdropFilter 的範圍跨過該視窗邊界；本次依截圖與圖層結構移除對話框的背景模糊，改成淡藍色半透明填色，保留邊框與原本角色位置，避免取樣原生圖層邊界。這是針對合成問題的修正，仍需手機再次顯示對話框確認。
