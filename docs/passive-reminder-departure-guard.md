# 離席過渡提醒保護與分心參數

更新日期：2026-10-14。

## 這次修改

只保護正式 App 的被動語音提醒，不更改視覺分類器、原生 MediaPipe 或雙軌 CSV 判斷結果。

- 剛進入分心／睡眠、臉剛消失、身體明顯移動時，開啟 800 毫秒觀察窗。
- 觀察窗與原本提醒證據累積同時進行，不是每句語音固定再等 800 毫秒。
- 時間到後須有新的偵測樣本確認，單靠計時到期不會播放。實際等待也受採樣間隔影響；fallback 影片目前每 800 毫秒取樣。
- 身體移動線索沿用既有姿勢分數範圍：肩膀下降 >= 34、肩膀縮窄 >= 55、側趴 >= 65。轉頭則用剛進入分心的狀態開啟觀察窗，不因每次分數跨過 55 都重啟，避免反覆轉頭的提醒一直被延後。這些只用來暫緩提醒，不證明離席。
- 完全沒有臉與身體時暫不播被動提醒；只有身體、且目前仍判定睡眠時，觀察後可播睡眠提醒。
- 確認 `userMissing` 後清除待播提醒及其他狀態的未結束累積證據，避免快速回座後沿用離席前的證據。已記錄的事件次數不回溯刪除。
- 提醒記住判斷版本；狀態、原因或臉與身體完全消失後，舊請求失效，即使快速回到相同狀態也不復活。只有臉短暫消失、身體仍在且狀態與原因不變時，暫緩後可重新確認並播放。
- 音檔載入與播放器準備之後、真正呼叫播放之前，再檢查狀態版本、觀察窗、資料新鮮度、安靜模式及互動語音狀態。
- 主動詢問 AI 的回覆和喚醒回應不需要通過這個視覺檢查。

這不能預知未來離席，也不撤回已經播放的音訊；使用者先轉頭停留數秒才離席時，仍可能已經收到分心提醒。800 毫秒是起始設定，尚未用新實機錄影驗證最佳值。視覺 UI 和原始事件紀錄仍可能顯示過渡分類，本次不是重寫離席分類器。

實作：`lib/voice/passive_reminder_guard.dart`、`lib/screens/face_detection_screen.dart`、`lib/focus/focus_session_monitor.dart`。

## 正式 App 的分心邏輯

不是眼球注視點辨識，也不是「快速看別處就一定分心」。使用原生頭部偏移分數（0～100，不是角度）及 Dart 時序判斷：

1. 最近 5 個有效樣本中有 3 個平滑後分數 >= 55，進入分心。
2. 分數 <= 30 連續 2 個樣本，解除分心。
3. 已判分心後，偏移分數穩定 6 秒、至少 4 個樣本、最大最小差 <= 14，且最高分 <= 75，視為穩定看同一方向，解除分心。
4. 因穩定偏頭解除後，要先回到分數 <= 30，才重新允許觸發。
5. 6 秒是解除條件，不是提醒等待時間。一般模式分心證據累積 3 秒就可提出語音提醒，所以穩定偏頭前段仍可能被提醒。
6. 另有無臉但肩膀穩定、非低頭的推斷路徑：持續 900 毫秒可能判分心，不只上述轉頭投票。

來源：`lib/vision/head_offset_detector.dart`、`lib/vision/companion_state_evaluator.dart`。

## 可調參數

目前是程式參數，不是 App 設定頁的選項。本次沒有修改這些數值。

| 參數 | 預設 | 意義 |
| --- | --- | --- |
| `enterThreshold` | 55 | 降低會更容易判分心 |
| `evidenceWindowSize` / `enterVotes` | 5 / 3 | 最近幾次觀測、至少幾次達門檻；次數不是固定秒數 |
| `exitThreshold` / `exitFrames` | 30 / 2 | 回正解除門檻與連續次數 |
| `settledGazeDuration` | 6 秒 | 偏頭穩定多久才解除 |
| `settledGazeSpread` | 14 | 穩定區間容許的分數變化；增大會更容易認定穩定 |
| `settledGazeMinSamples` | 4 | 穩定判定至少需要的樣本數 |
| `settledGazeMaxScore` | 75 | 更大的偏頭不走穩定解除 |
| `missingFaceHoldFrames` | 2 | 身體仍可見時，短暫丟臉可保留已成立分心的次數 |
| `faceMissingDistractionDuration` | 900 毫秒 | 無臉且肩膀穩定的分心推斷等待時間 |
| `FocusSessionMonitor.reminderThreshold` | 3 秒 | 一般模式分心語音的證據累積時間；與分類門檻不同 |
| `PassiveReminderGuard.observationDuration` | 800 毫秒 | 本次新增的過渡觀察時間 |
| `PassiveReminderGuard.maximumSampleGap` | 3 秒 | 超過此時間沒有新樣本，不用舊資料批准播放 |

雙軌離線實驗的 `--head-score-sum` 是另一種入口：5 次總和 >= 275，且至少 2 次實測分數 >= 55；符合條件的丟臉補 50。正式 App 預設 `useScoreSum = false`，本次不將這項實驗切入 App。

## 驗證

本次執行 `flutter test --no-pub test/voice test/focus test/vision`，208 個測試通過；修改的 5 個 Dart 檔案通過 `flutter analyze --no-pub`，沒有診斷問題。

單元測試涵蓋 800 毫秒及新樣本要求、身體仍在的睡眠、完全消失、快速離席回座、原因變更、校正重設、資料過時，以及音訊初始化／播放器準備期間離席時不呼叫播放。另驗證離席會清除舊累積證據，但保留歷史事件次數。

仍須實機確認：快速轉頭後起身、單純轉頭回正、低頭讀書、趴下、快速回座，以及正常 AI 對話。單元測試不等於已證明實機混播消失。
