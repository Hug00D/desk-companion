# 分心總分候選 Review

- 日期：2026-10-05；分支 `feature/vision-lab-dual-track`，未提交或推送。
- 需求：最近五次分數直接加總；缺臉遞補 50，避免純補分自行觸發。
- 範圍：可選的離線雙軌候選，正式 App 預設仍是原有 3-of-5；不改原生端或 MediaPipe。
- 資料：沿用 V1／V2 原始特徵和使用者事先確認的 GT，不重抽、不補寫原始缺值。
  兩片仍是開發資料，不是獨立驗證；不能當作朋友交接文件的指定驗收已通過。

## 規則

1. 收齊最近五次觀測後，總和至少 `275`，且其中至少兩次真實分數達 `55`，才啟動分心。
   `50 × 5 = 250` 不會觸發；單次 `100` 加四次 `50` 即使總分 300，也因真實高分不足而不觸發。
2. 有臉時使用原生已平滑的 `headOffsetScore`（限制在 0～100），新模式不再加一次 Dart
   OneEuroFilter，以保留短暫偏移的峰值。原本模式仍照舊使用該 filter。
3. 缺臉時只有近期有兩次真實高偏移線索、Pose 幾何可信、未因穩定注視解除且沒有離席／
   側向離開／相對肩膀下降／強趴下線索，才放入一筆 50。可延續已觸發事件，也可在
   五筆視窗內仍有兩筆真實高分時完成觸發；不憑缺臉猜測新事件。
   單獨使用 detector 預設不補分，必須由呼叫者明確開啟補分資格。
4. 補分最多橋接最後一次符合條件的真實高分後兩秒；補分本身不更新期限、不算真實高分，
   也不算穩定注視。到期或姿勢不可信就清除轉頭證據，回到 unavailable／unknown。
5. 延續原有解除條件：兩次真實分數 `<=30` 回正；或連續六秒真實分數穩定
   （範圍 `<=14`、最高分 `<=75`）後解除，直到回正再重新允許觸發。
6. 觀測間隔超過 500 ms 或校正／reset 時清除總分與補分資格；時間不倒退。
   總分只保留五筆，不隨使用時間持續堆積。
7. 離席與睡眠仲裁沿用上一版，不因補分取代這些狀態。進入相關分支會清除轉頭候選。

`275`、兩秒補分期限與兩次真實高分是本輪初始安全條件，未依影片另加專屬例外，尚未正式凍結。

## 使用

```powershell
dart run tool\vision_lab_dual_track.dart `
  vision_lab_out\frame_features_<runId>.csv `
  vision_lab_out\ground_truth_sleeping_<runId>.csv `
  vision_lab_out\head_score_sum_new_run `
  --window-ms=2000 --presence-context --head-score-sum
```

可改用 3000 ms；兩個功能旗標順序不限。僅指定 `--head-score-sum` 會拒絕執行，
避免沒有離席仲裁保護的缺臉補分。輸出拒絕覆寫，加 `_presence_headsum` 後綴。
新診斷欄位為 `head_score_state`、`head_score_used`、`head_score_imputed`、`head_score_sum`、
`head_score_samples`、`head_score_measured_high_samples`；補分與真正量測可分開檢查。
快軌四欄（幀號、PTS、status、cause）仍保留原正式 evaluator 結果，新模式只參與雙軌 final 仲裁。

## 驗證與停止點

- 全部 Vision 測試 139 項通過，其中本輪新增 26 項；四個修改的 Dart 檔 analyze 無問題。
- 新模式重跑的 12 份 CSV 位元組完全相同。
- 關閉新模式的 12 份輸出與原雙軌、只開離席模式的 12 份輸出與上一版離席候選，皆位元組相同。
- 兩片／兩視窗共 8074 次逐幀快軌欄位比對，全部一致；兩份原始特徵 CSV 不變。
- 測試涵蓋總分邊界、完整五筆、單次雜訊、純 50 分、兩高分＋補分、補分到期、缺身體、
  不可信幾何、離席、相對下降、穩定注視、回正、時間斷裂、reset 與不安全 CLI 參數。
- 總分不是已校正的注意力信心值。兩筆 100 加三筆真實 0 的總分只有 200，不會觸發；
  不能承諾所有只有兩幀的快速轉頭都必定抓到。
- 五筆視窗仍受取樣頻率影響，僅補分期限等時間規則使用 PTS；需要另外驗證實機不同 FPS。
- 頭部絕對偏移分數不等於眼睛注視點，也不能可靠區分快速對答案與真正分心；
  六秒穩定規則仍是舊設計近似，不在本輪重做。
- 停在候選 Review；下一輪需用未用於開發的快速轉頭、持續側看、對答案、離席與趴下影片驗證。
  不啟用正式 App，不替代 test6～test9 重跑與 test10／test11 的獨立規劃。
